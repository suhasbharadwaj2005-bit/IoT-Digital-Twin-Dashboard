# Project Setup and Running Instructions

## 1. Project Requirements

### Hardware

- ESP32 DevKit
- USB cable
- Sensors (optional, because the current prototype can use simulated data)

### Software

- Arduino IDE
- ESP32 Board Package
- PubSubClient Arduino Library
- Mosquitto MQTT Broker
- Node-RED
- Node-RED Dashboard
- MQTT Explorer

---
